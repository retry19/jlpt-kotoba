# Changelog

All notable changes to this project will be documented in this file.

## [Unreleased]

### Added

- Added the `Notes` column to all JLPT vocabulary datasets (`N1`–`N5`).
- Added additional N5 vocabulary entries and usage notes.
- Added the `Example` column to the N5 vocabulary dataset.
- Added more N5 adjective entries (e.g. 暖かい, 危ない, 忙しい, 暗い, 楽しい).
- Documented the five-column CSV schema and `Notes` guidance in `README.md`.
- Added an agent skill and shell script for validating `kanji_id` references.
- Added the N5 kanji and related vocabulary datasets.
- Added a CSV linting script and agent skill for validating dataset files.

### Changed

- Clarified the kanji dataset schema, optional values, relationships, and vocabulary types in `README.md`.
